# 爸妈别急 · 银发数字生活安全副驾

<p align="center">
  <strong>看懂当前一步，只给安全的下一步；遇到风险，先停下来。</strong>
</p>

---

## 🎯 这是什么

一个帮助老年人安全使用手机的 AI 副驾。当老人面对看不懂的手机页面、退款转账等潜在风险操作时，系统判断风险等级，**一次只给出一个清晰、可逆的下一步**，遇到危险立即停下并连接家人。

**小有可为 2026 · AIForGood 参赛项目**

## ✨ 核心特色

| 特色 | 说明 |
|------|------|
| 🔒 **AI 只能升级风险，不能降低** | 确定性规则是安全底线，视觉模型只能发现额外风险并提高等级 |
| 👣 **一次只给一个可逆步骤** | 不把整段教程抛给用户，每步都有明确动作和成功信号 |
| 🛑 **遇到风险立即停止** | 转账、验证码、屏幕共享等高风险场景，不提供任何继续按钮 |
| 🤷 **不确定时不瞎猜** | 截图缺失、画面模糊、结果冲突时进入 UNKNOWN，绝不 fail-open |
| 👨‍👩‍👧 **脱敏求助卡** | 把老人难以表达的页面问题整理成结构化求助内容发给家人 |
| 🔊 **语音输入 + 语音播报** | 支持语音描述问题、语音朗读步骤（rate=0.85 适老语速） |

## 🛡️ 安全设计

四种受控决策（输出只能落入这四类）：

```
GUIDE（继续指导）—— 低风险，仅从审核白名单教程选择
STOP（停止操作）  —— 高风险，生成脱敏求助卡
CLARIFY（补充信息）—— 不确定，引导重新描述
UNSUPPORTED      —— 超出能力边界，明确告知
```

安全不变量：
- 高风险**绝不**进入 GUIDE
- UNKNOWN **绝不**进入 GUIDE
- 视觉失败**不得**自动放行
- 每个指导步骤**只包含一个审核动作**与一个成功信号

## 📱 三条演示路径

| 路径 | 场景 | 系统行为 |
|------|------|---------|
| 🟢 低风险 | 微信没声音 / 字太小 | 一步指导 + 成功信号 + 语音播报 |
| 🟡 中风险 | 电商退款 | 只允许平台内安全步骤，出现付款/验证码立即升级 |
| 🔴 高风险 | 转账 / 验证码 / 屏幕共享 | 直接停止 + 脱敏求助卡 + 发给家人 |

## 🏗️ 技术架构

- **框架**：Next.js 16 + React 19 + TypeScript (strict)
- **架构**：六层分层（app / application / domain / contracts / infrastructure / lib）
- **AI**：Qwen Vision（可选，关键词规则兜底）
- **设计**：暖色调适老化 UI，WCAG AA 对比度，大字号高可读性
- **测试**：纯函数单元测试 + Playwright 三路径 E2E

## 🚀 快速开始

```bash
pnpm install
pnpm build
pnpm start    # http://localhost:3000
```

三条路径无需 API Key，纯关键词规则即可完整体验。
