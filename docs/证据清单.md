# 证据清单

按 P0 构建方案 §15 要求，严格区分以下证据等级。任何模拟结果、代码推导图片或固定样例都不得描述为真实运行成功。

## 证据等级定义

| 标签 | 含义 | 可信度 |
|---|---|---|
| [已实现] | 代码已写，typecheck/build 通过 | 代码存在 |
| [单元测试] | node --test 覆盖，pass | 逻辑正确 |
| [本地构建] | pnpm build 生产构建通过 | 可编译 |
| [本地浏览器] | pnpm dev 手动验证 | UI 可用 |
| [固定回放] | tests/fixtures 脱敏样例 | 非真实模型 |
| [真实模型调用] | 用真实 API Key 调 Qwen | ❌ 未做 |
| [线上部署] | 生产环境运行 | ❌ 未做 |
| [真实用户验证] | 老年用户可用性测试 | ❌ 未做 |
