# content/task-packs/ — 任务状态包

已审核、版本化的任务状态包（task packs）。

## 职责

每个任务包定义一个受控流程的状态机：合法的下一步、允许的动作（Allowed Action）、
成功信号。例如「微信通话声音恢复」「电商退款」等。

## 设计原则（方案 4.1 + 6.2）

- 任务包是**已审核的白名单**，AI 不能自由编造步骤，只能改写表述。
- 版本化：每个任务包带 `version`，决策响应回传 `taskPackVersion`（方案 8.1）。
- 任务包状态匹配失败时返回 `TASK_STATE_NOT_FOUND`（方案 8.2），不静默兜底。

P0 阶段的具体任务包在第二、第五阶段随领域逻辑迁移后填充。
